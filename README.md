# 🚗 Car Price Prediction System

A Machine Learning-based web application that predicts the estimated selling price of a car based on user-provided details.

## About the Project

This project uses Machine Learning algorithms to estimate car prices. Initially developed using Streamlit, the application was later upgraded to Flask with an HTML, CSS frontend.

## Features
- Predict estimated car prices.
- User-friendly web interface.
- Machine Learning model integration.
- Data visualization and analysis.

## Technologies Used
- Python
- Flask
- HTML & CSS
- Scikit-learn
- Pandas & NumPy
- Matplotlib & Seaborn

## Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/khushiranka0106/car-price-predictor-ml.git
```

2. Navigate to the project directory:

```bash
cd car-price-predictor-ml
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the Flask application:

```bash
python app.py
```

5. Open your browser:

```text
http://127.0.0.1:5000/
```
